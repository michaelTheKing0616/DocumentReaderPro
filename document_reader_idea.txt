Pupil Labs integration is added for hardware eye-tracking support, using the Realtime Network API (primarily ZeroMQ for streaming, HTTP for status/control), discovered via mDNS, with native ZeroMQ support via react-native-zeromq and react-native-zeroconf for device discovery. Tobii eye-tracking integration is included via Tobii Pro SDK/Streams SDK (free for developers), using native modules to bridge C++/Python bindings for real-time gaze streaming on supported platforms (Windows/Linux/Android); integration involves loading the SDK dynamically, connecting to hardware via USB/network, and streaming gaze data (e.g., via Tobii Interaction API or Stream Engine for coordinates/fixations). To make this the best, additional top eye-tracking hardware and SDKs are integrated based on 2025 standards: EyeLink (SR Research, high-precision research SDK with Python bindings); SMI (SensoMotoric Instruments, now part of Apple, with RED-m mobile tracker SDK for Android/iOS); Gazepoint (affordable GP3/GP Mini SDK with .NET/Python APIs); GazeSense (3D eye-tracking SDK for custom apps, webcam/device-agnostic with Unity/ROS support); and others like EyeQuant/Neurons Predict for AI-enhanced metrics, all via native modules or network APIs where available for comprehensive coverage.

The app prioritizes accessibility (WCAG 2.2 compliant), privacy (GDPR/HIPAA-ready with on-device processing where possible), and personalization via AI-driven profiles. Monetization could include freemium (basic reading free, advanced analytics/TTS premium) or subscription tiers.

Now integrated: Gaze360 dataset (via erkil1452/gaze360 repo or Hugging Face Morning5/Gaze360 mirror) for training 3D gaze models, using standard train/val/test splits (temporal windows of 7 frames).
